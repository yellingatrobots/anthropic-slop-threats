# Threat Intelligence Spin-O-Rama

Because reading 200 pages of Anthropic's September 2026 threat report is a lot of work, and JR and The Foz need a gimmick to pick their weekly dose of doom.

A single-file web app that simulates a game show slot machine to randomly select a case study from the [Anthropic Threat Intelligence Report](https://www.anthropic.com/threat-intelligence-report-september-2026), then generates a YAR-voice TL;DR and an AI slop title card prompt featuring Dario Amodei actively helping commit the crime in question.

## How it works

1. Press spin, coward.
2. Category reel locks in (Cyber Operations, Surveillance, Influence, Conventional Weapons, Biological Misuse, Scams, Illicit Distillation).
3. Case study reel spins within that category.
4. Get a TL;DR in the Yelling At Robots voice, complete with randomized byline about which host is doing the actual work while the other is off thinking about sourdough or yelling about bun rewrites.
5. Get an AI Slop Title Card Prompt for Josh to generate the episode thumbnail — every single one features Dario Amodei personally participating in the threat actor's scheme. Dario in a French police uniform selling stolen credit cards. Dario in a submarine writing anti-torpedo software for the PLA Navy. Dario in a hazmat suit feeding H5N1 to ferrets. You get the idea.
6. History of previous spins is immutable because we are not animals.

## Usage

Open `threat-topic-picker.html` in a browser. That's it. No build step. No npm install. No `vibe coding` required. We know how that ends.
